🌡️ MLX90640 Thermal Camera Wiring Guide

Complete reference for connecting MLX90640 to Raspberry Pi 3 B+

⚠️ CRITICAL WARNING:
  • MLX90640 requires 3.3V ONLY - connecting to 5V will damage the sensor!
  • Always power off Raspberry Pi before connecting/disconnecting wires
  • Double-check all connections before powering on

📋 Required Connections

MLX90640 Pin Wire Color Raspberry Pi Pin Pin Number Description
VIN Red 3.3V Power Pin 1 ⚠️ Must be 3.3V, NOT 5V!
GND Black Ground Pin 6 Any GND pin works
SDA Yellow GPIO2 (SDA) Pin 3 I2C Data line
SCL Blue GPIO3 (SCL) Pin 5 I2C Clock line
3V0 - UNCONNECTED - ⚠️ Output pin, leave empty!

🔍 Step-by-Step Connection Guide

Before You Start:

  1. ✋ Power OFF Raspberry Pi completely
  2. 📦 Gather materials: MLX90640, 4 jumper wires (female-to-female)
  3. 🔦 Work in good lighting

Connection Steps:

  1. Connect VIN (Power):
    • Take RED wire
    • Connect to MLX90640 VIN pin
    • Connect other end to Raspberry Pi Pin 1 (top-left corner, 3.3V)
    • ⚠️ Verify it's Pin 1 (3.3V), NOT Pin 2 (5V)!

  2. Connect GND (Ground):
    • Take BLACK wire
    • Connect to MLX90640 GND pin
    • Connect other end to Raspberry Pi Pin 6 (3rd row, right side)

  3. Connect SDA (Data):
    • Take YELLOW wire
    • Connect to MLX90640 SDA pin
    • Connect other end to Raspberry Pi Pin 3 (2nd row, left side)

  4. Connect SCL (Clock):
    • Take BLUE wire
    • Connect to MLX90640 SCL pin
    • Connect other end to Raspberry Pi Pin 5 (3rd row, left side)

  5. Leave 3V0 Unconnected:
    • The 3V0 pin on MLX90640 is an OUTPUT
    • Do NOT connect anything to it

✅ Verification Checklist

Before Powering On:

  • ☐ VIN connected to Pin 1 (3.3V) - NOT Pin 2!
  • ☐ GND connected to Pin 6 (or any GND)
  • ☐ SDA connected to Pin 3 (GPIO2)
  • ☐ SCL connected to Pin 5 (GPIO3)
  • ☐ 3V0 pin is left unconnected
  • ☐ All wires firmly inserted
  • ☐ No wires touching each other

After Powering On:

  1. Boot Raspberry Pi
  2. SSH into Pi
  3. Run: sudo i2cdetect -y 1
  4. Should see 33 in the output grid
  5. Run: cd ~/crack_detector && python3 test_thermal.py
  6. Should see temperature readings

🔧 Troubleshooting

If No Device Detected (No "33" in i2cdetect):

Problem Check Solution
Wrong voltage Is VIN on Pin 1 or Pin 2? Move to Pin 1 (3.3V)
Swapped wires Is SDA on Pin 3 and SCL on Pin 5? Swap them if reversed
Loose connection Are wires fully inserted? Push firmly into place
Wrong I2C pins Using Pin 3 and 5? Must use hardware I2C pins
I2C not enabled Run lsmod | grep i2c Enable in raspi-config
3V0 connected Is 3V0 pin connected? Disconnect it!

✅ Success Indicators:

  • sudo i2cdetect -y 1 shows 33 at row 30, column 3
  • python3 test_thermal.py shows temperature readings (20-30°C typical)
  • Web interface shows thermal camera feed

⚠️ Common Mistakes to Avoid:

  • Using 5V instead of 3.3V - This is the #1 mistake! Always use Pin 1 (3.3V)
  • Swapping SDA and SCL - SDA=Pin 3, SCL=Pin 5 (not the other way)
  • Connecting 3V0 pin - This is an OUTPUT, leave it empty
  • Using wrong GPIO pins - Must use hardware I2C (Pin 3 & 5)
  • Loose connections - Push wires firmly until they click
