SOLUTION 1: Manual Upload + Hard Restart
=================================================================

STEP 1: Upload file (PowerShell)

STEP 2: SSH into Pi
-------------------
ssh pi@192.168.168.127

(Enter password: raspberry)


STEP 3: Kill ALL analytics processes (on Pi)
--------------------------------------------
sudo pkill -9 -f web_data_analytics

(This FORCE kills all processes)


STEP 4: Verify file was uploaded (on Pi)
----------------------------------------
ls -lh /home/pi/web_data_analytics.py
grep -c "Number of Cracks" /home/pi/web_data_analytics.py

Expected output:
- File size: ~25KB or more
- Grep count: 0 (zero means manual input is removed!)

If grep shows 0 = SUCCESS! File is updated.

STEP 5: Start new version (on Pi)
----------------------------------
cd /home/pi
nohup python3 web_data_analytics.py > analytics.log 2>&1 &

Wait 3 seconds for startup.


STEP 6: Verify process is running (on Pi)
------------------------------------------
ps aux | grep web_data_analytics | grep -v grep

You should see:

If you see this = SUCCESS! Service running.


STEP 7: Check port is open (on Pi)
-----------------------------------
sudo netstat -tlnp | grep 8080

You should see:
tcp  ...  0.0.0.0:8080  ...  LISTEN

If you see this = SUCCESS! Port is open.


STEP 8: Exit Pi

=================================================================
TROUBLESHOOTING
=================================================================

Issue 1: "Permission denied" during upload
------------------------------------------
Run on Pi:
chmod 644 /home/pi/web_data_analytics.py


Issue 2: Service won't start
-----------------------------
Check error log on Pi:
tail -50 /home/pi/analytics.log

Common errors:
- Port 8080 already in use → kill process: sudo pkill -9 -f web_data
- Python module missing → install: pip3 install flask


Issue 3: Browser shows "Connection refused"
--------------------------------------------
Service is not running. On Pi:
ps aux | grep web_data_analytics

If empty, start it:
nohup python3 ~/web_data_analytics.py > ~/analytics.log 2>&1 &


Issue 4: Still shows old version after all steps
-------------------------------------------------
This means browser is caching aggressively.

Solution:
1. Open browser in INCOGNITO/PRIVATE mode
2. Go to: http://192.168.168.127:8080
3. Check if manual input is gone

If gone in incognito = Cache issue (clear cache)
If still there = Upload didn't work (try Solution 2)
