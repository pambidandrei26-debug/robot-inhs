PROMPT 1: MINIMALIST TECHNICAL ILLUSTRATION (RECOMMENDED)
================================================================================

Create a clean, minimalist technical illustration of an autonomous crack detection robot with the following specifications:

STYLE REQUIREMENTS:
- Clean white background
- Soft shadows under robot only
- Minimal text labels (only major components)
- Use leader lines with small dots at connection points
- Component colors: Robot chassis (sky blue), PCBs (actual colors), wires (color-coded but subtle)
- Isometric 3/4 view from front-left at 30-degree angle
- Professional product photography style
- No background grid or technical clutter

ROBOT STRUCTURE:
Base Platform (25cm x 15cm):
- Bright blue Makeblock aluminum chassis with rectangular perforations
- Two black rubber tank treads (left and right)
- Silver drive wheels visible inside treads
- Clean, smooth appearance

Electronics Bay (middle section):
- MegaPi controller board (blue PCB) mounted horizontally
- Raspberry Pi 3 B+ (green PCB) mounted above MegaPi
- Small blue buck converter module visible
- White rectangular battery pack (12V LiPo)
- Components neatly arranged, no wire mess

Vertical Arm (50cm tall):
- Single clean blue aluminum beam rising from base
- Articulated sections with visible pivot joints
- Arm motor (silver cylinder) at pivot point
- Black gripper/claw at top end

Front Sensors (mounted low, facing forward):
- Small ultrasonic sensor (two black cylinders side by side)
- Raspberry Pi camera (small black lens module)
- Tiny MLX90640 thermal sensor next to camera

LABELING STYLE:
Use only 8 main labels with thin leader lines:
1. "Articulated Arm" → pointing to vertical beam
2. "Gripper" → pointing to claw
3. "Raspberry Pi 3B+" → pointing to green board
4. "MegaPi Controller" → pointing to blue board
5. "Camera & Thermal" → pointing to front sensor cluster
6. "Ultrasonic Sensor" → pointing to HC-SR04
7. "Tank Treads" → pointing to one tread
8. "12V Battery" → pointing to battery pack

Place labels OUTSIDE the robot perimeter with clean horizontal lines, not overlapping.

WIRING:
Show only major power cables:
- Two thick red/black cables from battery (one to MegaPi, one to buck converter)
- One blue USB cable between MegaPi and Pi (subtle, not prominent)
- NO individual GPIO wires visible (keeps it clean)

LIGHTING:
- Soft directional light from top-left
- Gentle shadows underneath robot
- Slight reflection on aluminum surfaces
- No harsh highlights

DIMENSIONS:
Add a simple dimension indicator:
- Small dimension line showing "~50cm" height
- Small dimension line showing "~25cm" base width
- Placed subtly at edge of image

TECHNICAL SPECS BOX (optional, small, bottom corner):
┌──────────────────────────┐
│ Specifications:          │
│ • Height: 50cm           │
│ • Weight: 2kg            │
│ • Battery: 30-45 min     │
│ • 4 Sensors (RGBT+U+A)   │
└──────────────────────────┘

Keep this box SMALL (5% of image size) and place in bottom-right corner.

WHAT TO AVOID:
✗ Wire spaghetti showing every connection
✗ Too many labels pointing everywhere
✗ Cluttered background with grids
✗ Overly detailed component internals
✗ Text overlapping components
✗ Busy technical drawings style

WHAT TO EMPHASIZE:
✓ Clean silhouette of robot
✓ Blue Makeblock structure clearly visible
✓ Tank treads prominent
✓ Vertical arm impressive and clear
✓ Sensors visible but not overwhelming
✓ Professional product shot aesthetic

OUTPUT STYLE:
Think "Apple product page" clean design, not "engineering blueprint" busy style. 
The robot should look professional, modern, and easy to understand at a glance.
